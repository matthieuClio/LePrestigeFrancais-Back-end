# LePrestigeFrançais — Backend API

Backend API for **LePrestigeFrançais**, a French-learning platform focused on grammar, spelling, and interactive exercises.

The API will progressively handle user authentication, account management, and learning progress.

## Project status

**In development.** The application is currently being initialized.

## Tech stack

- Node.js
- TypeScript
- Express
- PostgreSQL
- Docker
